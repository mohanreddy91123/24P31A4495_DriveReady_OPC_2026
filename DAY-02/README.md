# Day 2 – Prompts, Memory and Python Agents

## Project
Sweet Crumbs Home Bakery – AI Customer Support Chatbot

## Objective
Build a business-specific AI chatbot using prompt engineering, few-shot examples, JSON output, conversation memory and Python fundamentals.

## Topics Practised
1. Messages and roles
2. System prompts
3. Few-shot examples
4. Structured JSON output
5. Conversation memory
6. Python dictionaries and JSON
7. Functions and type hints
8. Decorators
9. Exception handling

## Practical Implementations

### Practical 1 – Prompt Parts
Tested chatbot behaviour using a system prompt with and without explicit rules.

### Practical 2 – Few-Shot Examples
Created a customer enquiry classifier using ORDER, PRICE, DELIVERY and OTHER categories. Tested it with 10 customer enquiries.

### Practical 3 – JSON Output
Extracted customer order information into structured JSON and converted it into a Python dictionary.

### Practical 4 – Memory by Hand
Implemented conversation history using Python lists and tested memory trimming with MAX_TURNS = 2.

### Practical 5 – Custom Business Chatbot
Created a bakery menu dictionary, a price calculation function and a customised system prompt. Tested customer enquiries about prices, eggless cakes and delivery requirements.
