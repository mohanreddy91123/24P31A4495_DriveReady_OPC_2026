# Day 1 – Introduction to AutoCare AI

## Project Overview
AutoCare AI is an AI-powered Vehicle Service Management Assistant designed to help customers with vehicle maintenance and service enquiries.

## Topics Covered
- Groq API Integration
- LangChain and ChatGroq
- LLM Initialization using GPT-OSS 120B
- System Prompt Engineering
- Building a Basic AI Chatbot
- Testing Customer Queries
- Prompt Injection
- Prompt Guard Demonstration

## Implementation
- Connected Groq API using Google Colab Secrets.
- Initialized the language model.
- Created the AutoCare AI system prompt.
- Developed the `ask()` function.
- Tested vehicle maintenance, safety, booking and pricing questions.
- Tested Prompt Guard.

## Technologies Used
- Python
- Google Colab
- LangChain
- Groq API
- GPT-OSS 120B
- Meta Llama Prompt Guard 2 (22M)

## Safety Features
- Does not provide confirmed mechanical diagnoses.
- Recommends a qualified mechanic for serious vehicle problems.
- Does not invent service prices.
- Does not guarantee appointment availability without a booking integration.

## Current Limitations
- Real-time appointment booking is not yet integrated.
- Maintenance recommendations should be checked against the vehicle manufacturer's service schedule.
