# Day 1 – Introduction to AutoCare AI

## Project Overview
AutoCare AI is an AI-powered Vehicle Service Management Assistant designed to help customers with vehicle maintenance and service enquiries.

## Topics Covered
- Groq API integration
- LangChain and ChatGroq
- LLM initialization using GPT-OSS 120B
- System Prompt creation
- Building a basic AI chatbot
- Testing customer queries
- Prompt Injection
- Prompt Guard demonstration

## Implementation
- Connected Groq API using Google Colab Secrets.
- Initialized the language model.
- Created the AutoCare AI system prompt.
- Developed the ask() function.
- Tested vehicle maintenance, safety, booking and pricing questions.
- Tested Prompt Guard.

## Technologies Used
- Python
- Google Colab
- LangChain
- Groq API
- GPT-OSS 120B
- Meta Llama Prompt Guard
