# Day 1 – Introduction to Sweet Crumbs Home Bakery AI

## Project Overview

Sweet Crumbs Home Bakery is a bakery business that accepts cake orders through chat. This project aims to build an AI-powered assistant that answers customer questions and helps with bakery enquiries.

## Topics Covered

- Introduction to Large Language Models (LLMs)
- Tokens and context windows
- Temperature
- Hallucinations
- API integration
- System prompts
- Building a basic AI chatbot
- Testing AI responses

## Business Information

- Orders are made to order.
- Orders require 24 hours' notice.
- All cakes have eggless versions.
- Plum cake – ₹500
- Chocolate cake – ₹650
- Cupcake – ₹80

## Implementation

- Connected the Groq API.
- Initialized the language model.
- Created a bakery-specific system prompt.
- Developed a chatbot function.
- Tested customer questions.
- Explored temperature and hallucination.
- Practised memory and token usage.

## Technologies Used

- Python
- Google Colab
- LangChain
- Groq API
- GPT-OSS
